Установка

  1. Установите Java 21 с adoptium.net (для версий до 1.20.4 хватит Java 17).
  2. Скачайте установщик кнопкой выше и запустите его.
  3. Если Windows покажет предупреждение SmartScreen, нажмите «Подробнее» → «Выполнить в любом случае».
  4. Откройте лаунчер, создайте сборку или выберите готовую и нажмите «Играть».

Вопросы

Почему Windows или антивирус ругается?

Установщик не подписан платным сертификатом, поэтому Windows считает издателя неизвестным. Исходный код открыт, его можно проверить в репозитории.

Нужна ли лицензия Minecraft?

Для игры на лицензионных серверах нужен аккаунт Microsoft с купленной игрой. Офлайн-режим подходит для одиночной игры и серверов без проверки.

Где хранятся мои данные?

Всё лежит локально, в папке .quiet_launcher в вашем профиле пользователя. Лаунчер ничего не отправляет на сторонние серверы, кроме запросов к Mojang, Modrinth и Ely.by.

Это официальный продукт Mojang?

Нет. Это неофициальный лаунчер, он не связан с Mojang и Microsoft.
